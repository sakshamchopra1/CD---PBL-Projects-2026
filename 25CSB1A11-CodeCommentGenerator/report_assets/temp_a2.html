The server provides a full JSON REST API allowing any terminal, script, or external application to interact with the generator and security layer.

Method Endpoint Description Sample Payload
POST /api/generate Executes full AST+NLP comment generation with Agentic Security Layer check. {"code": "def foo(): pass", "prompt": "...", "engine": "rule_based"}
POST /api/security/scan Tests prompt or code against security layer for prompt injection and payload signatures. {"text": "Ignore previous instructions", "vector_type": "DIRECT_PROMPT_INJECTION"}
GET /api/security/logs Retrieves all recorded structured security audit log entries. None
POST /api/security/clear_logs Clears all audit logs for the current session. None
GET /api/health Returns server status, Python version, and active thresholds. None
